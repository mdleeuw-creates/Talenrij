# Talenrij

Learn related languages side by side. Every word sits next to its relatives, so you spot the patterns and remember three or four words at once.

Installable web app (PWA) that works offline. Live at https://mdleeuw-creates.github.io/talenrij/

- `index.html` – the whole app
- `sw.js` – service worker for offline use (bump `VERSION` on every change)
- `manifest.webmanifest`, `icons/` – install metadata
